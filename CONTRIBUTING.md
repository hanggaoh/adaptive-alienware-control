# Contributing

Run Test.ps1 on Windows before submitting changes. Keep pure selection tests separate from administrator lifecycle and physical acceptance tests. Include safe defaults, explicit enablement and restore paths. Never claim model support from a matching name alone. See docs/hardware-adapters.md.

Do not commit machine snapshots, logs, serial numbers, tokens, absolute personal paths or vendor game libraries. Redact diagnostic attachments. Do not disable security software to run this project.
